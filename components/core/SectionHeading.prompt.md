Use `SectionHeading` to open every section. Pair it with a `Badge` eyebrow.

```jsx
<SectionHeading
  eyebrow={<Badge tone="glass">Conteúdo</Badge>}
  title="Seis módulos do zero ao SaaS no ar"
  highlight="do zero ao SaaS"
  subtitle="Cada módulo termina com algo publicado, não com uma anotação."
/>
```

Only one phrase is highlighted, and it is the phrase that carries the promise.
